# Музыка

Кинь треки в папку своего типа — система подхватит их сама, ничего прописывать не нужно:

- `music/menu/`   — музыка меню/гаража
- `music/travel/` — музыка путешествий (езда по миру)
- `music/battle/` — музыка сражений (враги рядом)

## Формат файла

- **Форматы**: `.ogg` (рекомендуется — стримится, мало памяти), `.mp3`, `.wav`.
- **Имя файла = метаданные**: `Автор - Название.ogg`
  (пример: `Karl Casey - Big Shot.ogg` → в UI покажет название «Big Shot», автор «Karl Casey»).
  Если тире нет — всё имя станет названием, автор «Неизвестен».
- **Зацикливание**: для ogg включи Loop в настройках импорта, если трек бесшовный.
  Не обязательно — система сама переключит на следующий трек по окончании.

## Переопределение метаданных (опционально)

Если не хочешь переименовывать файлы — создай `music/metadata.json`:

```json
{
	"track_file_name.ogg": { "title": "Название", "author": "Автор" }
}
```

Ключ — имя файла (без пути). Записанное здесь имеет приоритет над именем файла.

## Как это работает в игре

- Тип выбирается по контексту: гараж открыт → menu; враги рядом → battle; иначе travel.
- Внутри типа трек выбирается случайно с весами: «любимый» играет чаще,
  «выключенный» не играет никогда (настраивается игроком в UI «Музыка» в шторке HUD).
- Переходы — кроссфейдом; выход из боя с задержкой, чтобы музыка не дёргалась.
- Атрибуция: название и автор показываются в UI (важно для CC-BY треков).
