# Документация проекта

`CLAUDE.md` в корне — карта проекта: что где лежит и ПОЧЕМУ сделано именно так. Читать первым.
Здесь — подробности по отдельным системам.

| Файл | О чём | Тип |
|---|---|---|
| `BLOCKS_TODO.md` | блоки: как добавить, что уже есть, числа оружия, материалы и рецепты | справочник + остаток работ |
| `PROGRESSION_DESIGN.md` | грейды, XP, ДИ, древо, откуда берутся все цены | как устроено |
| `QUESTS_DESIGN.md` | типы квестов, стадии, обучение, квестовые предметы | как устроено |
| `STORY_ROADMAP.md` | сюжетная линия: сделано / очередь / отложено и почему | план |
| `STATIONARY_BLOCKS_DESIGN.md` | базы и стационарные блоки, якорь | как устроено |
| `CANYON_TERRAIN.md` | каньоны в карте высот; правки рельефа в игре и их запекание; швы LOD | как устроено + инструкция |
| `PROPS_HOWTO.md` | как раскидать пропы по биомам (для художника) | инструкция |
| `ROCKET_BLOCK.md` | как вставить свои модели в оружие, не сломав наводку; ракетница | инструкция |
| `atom_picker_reference.md` | откуда взялся глобус выбора блока | историческая справка |
| `../addons/LiteTerrain/README.md` | сам аддон рельефа (он НАШ, правится свободно) | документация аддона |
| `../music/README.md` | как добавлять музыку | инструкция |

Правило то же, что и для комментариев в коде: **доки объясняют ПРИЧИНУ**, а не пересказывают
действие, и обновляются вместе с поведением. Числа здесь — пересказ кода; источник правды —
`G.gd` и сами скрипты.
