# Референс инвентаря-«атома» (прототип игрока, CxxDroid/SDL2)

Модель, по которой сделан block_globe.gd:
- центральная сфера-ядро;
- горизонтальное «мастер-кольцо» (обод/экватор) = выбор ТИПА (красное);
- 4 кольца-меридиана на общей оси, наклонены веером (tiltY 45/90/135/180°),
  каждое своего цвета = категория, несут блоки-точки;
- общий вид-трансформ: rotateY(-45) затем rotateX(90) (смотрим вдоль оси).

РЕШЕНО с игроком по движению (в статичном прототипе не видно):
- 1A: крутим селектор → весь атом КУВЫРКАЕТСЯ в 3D, нужная категория выезжает
  вперёд и раскрывается (её блоки веером); остальные наклонены назад (тусклы).
- 2A: блок внутри типа — ПРОКРУТКОЙ активного кольца (тап берёт центральный).

Реализация в игре: перспективная камера в SubViewport, реальные меши блоков,
кольца-меридианы на оси-шпинделе (наклон psi вокруг оси), кувырок = _tilt.
