# Референс инвентаря-«атома» (прототип игрока, CxxDroid/SDL2)

Модель, по которой сделан `block_globe.gd` — глобус выбора блока в режиме стройки:

- центральная сфера-ядро;
- горизонтальное «мастер-кольцо» (обод-экватор) = выбор ТИПА (красное);
- кольца-меридианы на общей оси, по одному на тип, наклонены веером, каждое своего цвета =
  категория, несут блоки-точками;
- общий вид: смотрим на атом чуть сверху, вдоль оси.

РЕШЕНО с игроком по движению (в статичном прототипе этого не видно):

- **1A**: крутим селектор → весь атом кувыркается в 3D, нужная категория выезжает вперёд и
  раскрывается (её блоки веером); остальные наклонены назад и тусклы.
- **2A**: блок внутри типа выбирается ПРОКРУТКОЙ активного кольца, тап берёт тот, что в точке
  выбора.

## Что из этого вышло в игре

Перспективная камера в SubViewport, реальные меши блоков, кольца-меридианы на оси-шпинделе.
Жесты разошлись по осям: драг ВЛЕВО-ВПРАВО крутит атом (выбор категории), драг ВВЕРХ-ВНИЗ
листает переднее кольцо (выбор блока), тап без движения берёт то, что в точке выбора. Ось
жеста лочится по первому движению, иначе диагональный свайп менял бы и то, и другое.

Одна поправка против прототипа, найденная уже в игре: меридианы расставлены через **45°**, а не
через 90°. При 90° переднее и заднее кольца совпадали по плоскости и выглядели одним — из-за
этого казалось, что категорий вдвое меньше.
