# ТЗ: стационарные блоки (базы, как в TerraTech)

Статус: проект, обсуждаем. Первый стационарный блок — **ПРОДАВЕЦ (SELLER)**.

## Что это (со слов игрока)
- Блоки как машина, но **при спавне всегда на якоре**, взять и поехать нельзя.
- Стационарный блок **нельзя прикрепить к машине**, но **можно к другому стационарному** —
  при условии, что тот **может встать на якорь**.
- На стационарный блок **можно переключить камеру**, как на машину.
- У него есть **2D-кнопка над объектом + круговое UI** (как у машин).

## Существующая архитектура — что переиспользуем (всё уже есть)
| Нужное | Готовый хук |
|---|---|
| «Объект = машина» | `vehicle_body_3d.gd` (RigidBody3D) + узел `blocks` (blocks.gd) + метод `take_block_into_hand` |
| В списке камеры | `camera_controller.vehicles` = дети-RigidBody3D с `take_block_into_hand`; `switch_to_vehicle` |
| Якорь (стоит, не едет) | `toggle_anchor()` → `freeze=true`, `anchored=true`, колонна, выравнивание; флаг `anchored` |
| Круговое меню над объектом | машина (faction 0) сама создаёт `VehicleInteractButton` (Area3D, `vehicle_body_3d.gd:170`) |
| Спавн структуры «на землю» | поток кабины: `_cabin_ground` → `load(player_vehicle.tscn)` → `apply_build([CABIN])` → регистрация в `camera.vehicles` (`vehicle_body_3d.gd:~904`) |
| Правила прикрепления | `blocks.can_attach(neighbor, new, face)` |

Вывод: стационарная структура — это **та же машина-RigidBody**, но: спавнится сразу
`anchored`, якорь снять нельзя (нет движения), «ядро» — стационарный блок вместо кабины.

## Предлагаемый дизайн

### 1. Флаг «стационарный» у блока и у структуры
- В `G.BLOCK_META` (или отдельной константе `STATIONARY_BLOCKS`) помечаем типы-стационары:
  пока `[Block.SELLER]`.
- Структура (RigidBody-машина) получает флаг `is_station := true`, если её «ядро» —
  стационарный блок. Стационарная структура:
  - спавнится с `anchored=true` (переиспользуем логику якоря без анимации-подъёма);
  - `toggle_anchor()` для неё **заблокирован** (снять нельзя → ехать нельзя);
  - физика движения (`_physics_process` двигатель/руль) не работает (она и так `freeze`).

### 2. Спавн (переиспользуем «ядро на землю»)
- Берём SELLER в руку (глобус стройки), но при постановке на ЗЕМЛЮ (а не на машину) —
  как сейчас кабина — спавним **новую стационарную структуру** с SELLER-ядром
  (свой `player_vehicle.tscn`-подобный каркас или тот же, но `apply_build([SELLER как ядро])`
  + `is_station=true` + мгновенный якорь).
- На машину SELLER поставить **нельзя** (см. правила ниже) — только на землю/на др. стационар.

### 3. Правила прикрепления (`can_attach`)
- Стационарный `new_type` + сосед — **обычная машина** → `false` (нельзя на машину).
- Стационарный `new_type` + сосед — **стационарная структура, способная на якорь** → `true`.
- Обычный блок на стационарную структуру — решаем (по умолчанию: только стационары на
  стационары, обычные фабричные/оружие — нет; или разрешить? — ОТКРЫТЫЙ ВОПРОС).
- Технически: `can_attach` знает тип соседа, но не «машина/структура» — прокинем контекст
  (структура передаёт `is_station` в blocks, либо проверяем родителя).

### 4. Камера + круговое UI — бесплатно
- Даём стационарной структуре `take_block_into_hand` (как у машины) → попадёт в список
  камеры, `switch_to_vehicle` работает. `VehicleInteractButton` создаётся тем же кодом
  (faction 0). Круговое меню — то же (в инвентарь/разобрать/защита; для продавца, возможно,
  свои пункты — позже).

## РЕШЕНО игроком
1a — спавн: SELLER из инвентаря на ЗЕМЛЮ → стационарная структура (реюз потока кабины).
2a — SELLER теперь ТОЛЬКО стационар (на мобильную машину не ставится).
3b — на стационарную структуру можно ставить стационары И обычные фабричные (база-фабрика).
4a — ядро структуры = сам SELLER (гибель ядра = структура разбирается).

## Открытые вопросы (решить до старта)
1. **Как спавнить стационар?** (реком.) Ставим SELLER из инвентаря на ЗЕМЛЮ → структура
   (реюз потока кабины). Или отдельная кнопка/меню спавна? 
2. **SELLER перестаёт быть блоком машины?** (реком.) Да — SELLER теперь только стационар,
   на мобильную машину не ставится (это и есть «нельзя прикрепить к машине»). Или оставить
   двойным (и на машине, и как структура)?
3. **Что можно ставить на стационарную структуру?** Только другие стационары, или ещё
   обычные фабричные (коллектор/конвейер), чтобы строить базу-фабрику? (реком.) пока только
   стационары; фабричную обвязку — отдельным решением.
4. **«Ядро» структуры** — сам SELLER является ядром (гибель = структура разбирается), как
   кабина у машины? (реком.) да.
