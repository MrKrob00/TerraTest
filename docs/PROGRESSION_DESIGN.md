## 1. Как это устроено в TerraTech (референс, проверено)

### Корпорации (фракции)
| Корпа | Специализация | Когда встречается |
|---|---|---|
| **GSO** (Galactic Survey Org.) | универсал-стартер: всё понемногу, дёшево и слабо, но самый широкий ассортимент | со старта (игрок — проспектор GSO) |
| **GeoCorp** | тяжёлая индустрия: ковши, буры, огромные блоки 2×2+ | миссия «Big Yellow» с **GSO гр.2** |
| **Venture** | скорость: лёгкие блоки, гонки, ускорители | миссия с **GSO гр.3** |
| **Hawkeye** | военные: броня, максимум огневой мощи | миссия с **GSO гр.4** |
| **Better Future** | хайтек: ховеры, лазеры, антиграв | миссия с **GSO гр.4** |
| Reticule Research | экспериментальные блоки | **GSO гр.5** + почти все сюжетки |

Суть: у каждой корпы **свой характер, свои блоки на каждую роль** (колесо GSO ≠ колесо GeoCorp),
**своя линейка миссий**, и все корпы открываются через грейды стартовой GSO.

### Лицензии и грейды (проверенные числа)
- **GSO — 5 грейдов**; **GeoCorp / Venture / Hawkeye / Better Future — по 3**; RR — ~3.
- **XP корпы**: (а) её **миссии** (главный источник: крейт блоков + деньги + XP); (б) **убийства
  вражеских техов** — XP идёт корпе, чьих блоков в технике врага больше по стоимости.
  **Продажа даёт только деньги, НЕ XP.** После макс. грейда переполнение XP даёт награды
  (бесплатный Payload Terminal корпы).
- Грейд N открывает: **блоки грейда N в магазине станции и в крейтах**, **пул вражеских техов**
  подтягивается, **новые миссии**; вехи: с GSO-2 спавнятся инвейдеры, с GSO-3 — SCU-склад.

### Как игрок получает блоки
1. **Ранняя игра:** трофеи с уничтоженных врагов (падают физически) + крейты миссий. ВАЖНО:
   **подобранный блок можно ставить БЕЗ лицензии** — грейд гейтит только магазин и пул врагов.
   Инвейдеры могут принести блок сильно выше твоего грейда — бесплатный топ.
2. **Средняя/поздняя:** покупка за Block Bucks. Payload Terminal корпы — бесконечный сток, но
   только уже **«открытых» (discovered)** блоков: неизвестный блок сначала открой (крафт/крейт).
3. **Крафт** (Auto Miner → Refinery → Component Factory → Fabricator): ~в 3 раза дешевле покупки
   и «открывает» блоки, но громоздкий — на практике нишевый.

### Есть ли в TerraTech дерево технологий?
**Нет — подтверждено.** Вся прогрессия — экран лицензий с XP-полосами + механика discovered-блоков.
R&D Labs — это песочница-полигон (DLC), не исследования. Дерево мы ДОБАВЛЯЕМ поверх — наш плюс.

### Уроки аналогов (Crossout / Robocraft / Trailmakers / Scrap Mechanic)
- **Robocraft** (дерево блоков): хвалили прозрачный бюджет («343 очка = всё дерево», 1 очко/уровень)
  и **правило смежности** (открываешь только соседа изученного). Убили игру: лутбоксы вместо
  дерева и 4 смены системы прогрессии за 3 года. Урок: **никакого RNG, систему не перезапускать**.
- **Crossout** (репутация фракций): хорошо — репутация просто за игру, прогресс всех фракций
  сохраняется. Жалобы — суточный кулдаун смены фракции и **двойной гейт** («уровень открыл только
  верстак, деталь ещё скрафть»). Урок: **у нас XP всех фракций копится параллельно, без «активной»**.
- **Scrap Mechanic**: валюта гейта редким RNG-дропом = сломанный спрос. Урок: гейт — время игры,
  не дроп.
- **Мобильный UX дерева**: вертикальные ярусы (не радиалка), узлы ≥48dp, 4 состояния узла
  (изучен / можно / не хватает валюты / закрыт), «1-й тап — превью, 2-й — купить», разблокировку
  праздновать; первые 5-7 узлов — за первую сессию.

## 3. Предлагаемый дизайн

### 3.1 Фракции — развиваем текущие категории (не ломаем UX)
Категории уже прошиты в гараж-фильтры и глобус стройки (цвета!). Делаем их фракциями:

| Ключ | Фракция | Характер | Блоки сейчас |
|---|---|---|---|
| `blocks` | **Базовые** (вне фракций) | каркас, всегда доступны | BLOCK, CABIN, WHEEL |
| `attack` | **Милитех** (красный) | оружие, броня | GUN, LASER, DRILL |
| `factory` | **Индустрия** (янтарный) | добыча и переработка | COLLECTOR, INTAKE, BELT, PROCESSOR, SELLER, GENERATOR |
| `other` → `energo` | **Энерго** (фиолетовый) | энергия и защита | BATTERY, SOLAR, REGEN, SHIELD |

- 3 фракции с грейдами **1–3** — ровно как у корп TerraTech (кроме стартовой GSO с её 5).
- «Базовые» — без грейдов, доступны с начала (иначе нечем играть); играют роль «GSO гр.1».
- Позже — 4-я фракция новых блоков (ховеры/скорость а-ля Venture).
- **XP всех фракций копится параллельно** — никакой «активной фракции» и кулдаунов на смену
  (главная жалоба Crossout).
- **Трофеи вне лицензий (как в TerraTech):** блоки с убитых врагов и от пылесоса ставятся и
  используются БЕЗ грейда — грейд гейтит только МАГАЗИН. Сохраняет азарт мародёрства: враг
  может принести блок выше твоего уровня.

### 3.2 XP фракций — из того, что уже репортится
Хук готов: `Q.report(event, amount)` — дублируем событие в XP фракций:
- `ore_mined` → XP **Индустрии**
- `enemy_killed` (+ урон нашим оружием) → XP **Милитех**
- энергия сгенерирована / поглощено щитом (новые репорты в generator/solar/shield) → XP **Энерго**
- Квесты получают поля `reward_xp` + `faction` — квесты фракций как в TerraTech миссии корп.

Пороги грейдов: таблично в G, напр. `[0, 100, 400]` (настроим по балансу).

### 3.3 Грейды открывают (как в TerraTech)
1. **Магазин**: у каждого блока — `{faction, grade}`; в SHOP заблокированные слоты видны, но серые с замком «Индустрия ур.2» (показывать цель = мотивация).
2. **Квесты фракции** следующего грейда.
3. Позже — тиры врагов подтягиваются к максимальному грейду игрока.

### 3.4 Древо технологий — отдельный слой ПОВЕРХ грейдов
Грейд = «лицензия» (доступ купить). Дерево = **исследование** (открыть сам блок). Зачем оба:
грейд растёт сам от игры (XP), а в дереве игрок **выбирает путь** — это и есть «что качать первым».

- Валюта: **Данные исследований** (ДИ) — из квестов, первых убийств новых врагов, вех добычи.
  Гейт — время игры, никогда не редкий дроп (урок Scrap Mechanic). **Бюджет прозрачный**: в UI
  видно «исследовано X из N, всего нужно M ДИ» (урок Robocraft).
- Нода дерева = тип блока (позже — и апгрейды/подтипы Mk2). Условия ноды: **родитель исследован
  (правило смежности)** + грейд фракции + цена в ДИ.
- **Исследование сразу даёт 1 экземпляр блока в инвентарь** + открывает его в магазине. Никакого
  двойного гейта «исследовал, а теперь ещё накопи» (главная жалоба Crossout/Robocraft).
- Структура: 3 ветви от корня (кабина), по фракции на ветвь:

```
                    [КАБИНА]
                   /    |    \
        Милитех        Индустрия       Энерго
        ДРЕЛЬ          КОЛЛЕКТОР       СОЛНЕЧН.
          |            /      \           |
        ПУШКА      ЗАБОРНИК  ГЕНЕРАТОР  БАТАРЕЯ
          |            |         |        |
        ЛАЗЕР       КОНВЕЙЕР  ПРОДАВЕЦ  ЩИТ — РЕГЕН
                       |
                    ПРОЦЕССОР
```

- **UI (мобайл):** вкладка гаража «ДРЕВО» (`TAB_TECH`): три вертикальные колонки-ветви в
  ScrollContainer, ноды — крупные кнопки ≥48dp (превью блока из кеша глобуса + имя + цена в ДИ),
  **4 состояния**: исследовано / можно купить / не хватает ДИ / закрыто (замок + причина).
  Паттерн покупки: **первый тап — превью-панель** (что даёт, цена, требования), **второй —
  подтверждение**; разблокировка празднуется (вспышка/звук). Вертикальные ярусы, никаких
  радиальных схем. Кривая: **первые 5-7 нод — за первую сессию**, дальше ~1 нода за сессию.

### 3.5 Подтипы блоков (второй этап)
Как «колесо GSO vs колесо GeoCorp»: варианты того же слота — «Лазер Mk2» (урон↑, энергия↑),
«Батарея Mk2» (ёмкость↑) — новые ноды дерева за старшими грейдами. Требует минимума арта:
тот же меш + материал-акцент фракции.

### 3.6 Персист (обязательный фундамент)
Сейчас теряется всё, кроме сборок. Новый `user://progress.json` в G:
`money, block_inventory, faction_xp{}, researched[], done-квесты`. Без этого прогрессия бессмысленна.

## 4. План реализации (по команде)

| Этап | Что | Объём |
|---|---|---|
| **0. Фундамент** | персист G (money/inventory/xp/researched); структуры фракций в G (`FACTIONS`, `BLOCK_META {faction, grade, research_cost}`) | небольшой |
| **1. Фракции+грейды** | XP-репорты (ore/kill/energy), пороги, гейтинг SHOP (замки с причиной), полоска XP в гараже, реплики Механика при новом грейде | средний |
| **2. Древо** | вкладка TAB_TECH: 3 колонки, ноды с превью, валюта ДИ (награды в квестах), исследование | средний |
| **3. Квесты фракций** | цепочки на фракцию (по 3-4), награды ДИ+XP | небольшой |
| **4. Подтипы/тиры** | блоки Mk2 как ноды, тиры врагов от грейда | отдельно |

Этапы 0–1 самодостаточны (уже «как в TerraTech»); дерево — этап 2.
