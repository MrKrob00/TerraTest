# ТЗ: прогрессия (стартовая фракция, грейды, древо технологий)

Статус: утверждается. Референс TerraTech (проверен вебом): у GSO 5 грейдов, у прочих корп по 3;
XP = миссии + убийства (продажа не даёт); трофеи ставятся без лицензии — грейд гейтит только
магазин; явного дерева в TerraTech нет — древо наша надстройка. Анти-уроки аналогов: без RNG-гейтов,
без двойного гейта «исследовал → ещё крафти», без «активной фракции» с кулдауном.

## 1. Данные (G.gd)

```gdscript
# --- фракции (сейчас одна, структура под много) ---
const FACTIONS := { "start": { "name": "???", "grades": 5, "xp_thresholds": [0, 100, 300, 700, 1500] } }
# --- метаданные блоков: фракция + грейд + цена исследования ---
const BLOCK_META := { Block.CABIN: {"f": "start", "g": 1, "rp": 0}, ... }   # все 15, см. §2
var faction_xp := {"start": 0}          # XP по фракциям
var research_points := 0                # ДИ — валюта дерева
var researched: Array[int] = []         # исследованные Block-ы
```

Персист: `user://progress.json` = `{money, block_inventory, faction_xp, research_points, researched, quests_done}`.
Сохранять: debounce ~1с после изменения + при паузе/выходе. Загрузка в `G._ready`.
Сейчас money/inventory НЕ сохраняются — это чинится здесь же.

API в G:
- `add_faction_xp(f, amount)` → при переходе порога сигнал `grade_up(f, new_grade)`
- `grade(f) -> int` — текущий грейд
- `is_block_shop_unlocked(block) -> bool` — `researched.has(block) and grade(meta.f) >= meta.g`
- `research(block) -> bool` — проверка (смежность+грейд+ДИ), списание ДИ, +1 блок в инвентарь, сейв

## 2. Раскладка блоков (черновик — утвердить)

| Грейд | Блоки | ДИ за ноду |
|---|---|---|
| 1 | CABIN (корень, открыт), WHEEL, BLOCK, DRILL, COLLECTOR | 0 / 5 / 5 / 10 / 10 |
| 2 | INTAKE, BELT, GUN, SOLAR | 15 |
| 3 | PROCESSOR, SELLER, BATTERY | 20 |
| 4 | LASER, GENERATOR | 30 |
| 5 | REGEN, SHIELD | 40 |

Старт игры: исследованы CABIN, WHEEL, BLOCK, DRILL, COLLECTOR (иначе нет цикла денег).

## 3. Правила

- **XP** (все источники → `add_faction_xp("start", ...)`):
  - квест выполнен: новое поле квеста `reward_xp` (story: 20-50, daily: 10-20)
  - `enemy_killed`: +15
  - `ore_mined`: +1
- **ДИ**: награда квестов (новое поле `reward_rp`, story: 5-15, daily: 3-5) + первое убийство
  каждого нового врага +5. Никаких ДИ из дропа.
- **Гейтинг**: только SHOP гаража. Трофеи (дроп врагов, пылесос) ставятся всегда.
- **Дерево** (рёбра — см. эскиз §4): нода доступна ⇔ родитель исследован ∧ `grade(f) >= g` ∧ `research_points >= rp`.
  Исследование: −ДИ, `researched.append`, **+1 экземпляр блока в инвентарь**, блок появляется в SHOP.

## 4. Дерево стартовой фракции (рёбра)

```
CABIN → DRILL → GUN → LASER
CABIN → COLLECTOR → INTAKE → BELT → PROCESSOR
        COLLECTOR → GENERATOR → SELLER
CABIN → SOLAR → BATTERY → SHIELD → REGEN
CABIN → WHEEL;  CABIN → BLOCK
```
Одна страница на фракцию; ветви по ролям (оружие/добыча/энергия). Новая фракция = новая страница.

## 5. UI

1. **SHOP (tech_ui.gd)**: неоткрытый блок — серый слот + «🔒 Грейд N» или «🔒 Исследуй в древе».
   Кнопка покупки disabled.
2. **Полоска XP + грейд** стартовой фракции — шапка гаража (рядом с `%Currency`); там же счётчик ДИ.
3. **TAB_TECH «ДРЕВО»** (новая вкладка `tech_ui`): ScrollContainer, вертикальные ярусы по грейдам,
   ноды ≥48dp с превью блока (кеш `_visual_template` из block_globe переиспользовать нельзя напрямую —
   он в SubViewport; для нод рендер иконки или цвет+имя, решить на этапе 2).
   Состояния ноды: исследована / доступна / не хватает ДИ / закрыта (замок + причина текстом).
   Тап 1 — панель превью (что даёт, цена, требование), тап 2 — «Исследовать». Анимация на разблокировку.
   Шапка: «Исследовано X/15 · ДИ: N».
4. **Grade-up**: реплика Механика (`Q._say_lines`) + тост «Грейд N: открыто в магазине: …».

## 6. Этапы и критерии готовности

| Этап | Делаем | Готово когда |
|---|---|---|
| **0** | G: BLOCK_META/FACTIONS/поля/API/персист progress.json | деньги+инвентарь+XP переживают перезапуск; юнит-путь: research() списывает и выдаёт |
| **1** | XP-репорты, grade_up, гейтинг SHOP, полоска XP, реплика Механика | заблокированный блок не купить, замок объясняет почему; грейд растёт от квестов/убийств |
| **2** | TAB_TECH: дерево, ноды, исследование | путь CABIN→…→SHIELD проходится игрой; +1 блок падает в инвентарь при исследовании |
| **3** | Квесты с reward_xp/reward_rp, 3-4 цепочки на грейд | квесты выдают XP и ДИ, новые открываются по грейду |
| **4** (позже) | новые фракции (строка в FACTIONS + страница дерева + миссия-лицензия), Mk2, тиры врагов | — |

Каждый этап: код → адверсариальная проверка агентом → фикс → пуш (как обычно в этой сессии).
