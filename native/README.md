# native — прототип GDExtension для высот рельефа

**Это заготовка, а не часть сборки.** Игра работает без неё и ничего отсюда не грузит. Лежит тут,
чтобы не пропала: написана и замерена, но не доведена до применения.

## Что в ней

`TerrainNative` повторяет на C++ горячую середину `LiteTerrainGen`: сырую высоту в точке и
выборку сетки чанка. Ничего больше — ни биомов, ни каньона, ни сборки меша.

## Замеры

Сравнение с тем же кодом на GDScript, на этой же машине:

| | GDScript | C++ | во сколько |
|---|---|---|---|
| `raw_height_at`, мкс на точку | 22.78 | 3.30 | 6.9 |
| 25 сеток чанков, мс | 320.3 | 25.7 | 12.4 |

## Почему не применено

**Высоты — это не всё время загрузки.** На момент замера кольцо мира строилось 1.09 с, и высоты
в нём около трети. Остальное — `_mesh_arrays`: вершины, нормали, цвет вершин с масками биомов.
Перенести только высоты значит забрать треть от трети.

Честный порт должен утащить и сборку меша, а это уже не прототип на сто строк.

## Чего для сборки под телефон нет

Android NDK в контейнере недоступен: `dl.google.com` закрыт прокси, пакета в apt нет. То есть
собрать `.so` под arm64 отсюда нельзя — только под linux x86_64, для замеров.

## Как собрать (linux, для замеров)

```sh
git clone --depth 1 -b 4.5 https://github.com/godotengine/godot-cpp /tmp/gdcpp
cd native && scons platform=linux target=template_debug godot_cpp=/tmp/gdcpp
```

Ветка godot-cpp 4.5 берётся намеренно: её заголовки forward-совместимы с 4.6.
